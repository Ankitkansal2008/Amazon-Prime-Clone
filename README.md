# Amazon-Prime-Clone

A static HTML/CSS clone of the Amazon Prime Video landing page — a hero banner,
three horizontally scrollable movie rows, and a footer.

## Run it

No build step and no dependencies. Just open `index.html` in a browser, or serve
the folder locally:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Files

- `index.html` — page markup
- `style.css` — all styling
- `*.jpg` — poster images used by the hero and the movie cards
